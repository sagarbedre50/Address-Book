# Address Book

## Address Book Project Using C

### Project Overview

Address Book is a menu-driven contact management application developed using C programming. It allows users to create, search, edit, delete, and display contacts.

Contact details such as Name, Phone Number, and Email Address are stored in a file using file handling.

### Features

- Create new contacts
- Search contacts
- Edit existing contacts
- Delete contacts
- Display all contacts
- Save contact details
- Load saved contacts
- Save and Exit
